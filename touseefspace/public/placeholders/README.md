# Local Placeholder Images Directory

This directory (`public/placeholders/`) is where you can drop your own images, screenshots, and diagrams for the website.

---

## 📁 Pre-configured Placeholders:

1. **`aunvu-dashboard.svg`**: Used as the preview for **Aunvu / MISBAH ERP**.
2. **`ai-workflow.svg`**: Used as the preview for **AI Workflow & Extraction Suite**.
3. **`client-portal.svg`**: Used as the preview for **Real-Time Client Analytics SaaS**.

---

## 📸 How to use your own images:

1. Copy your `.png`, `.jpg`, or `.webp` file into this folder (`public/placeholders/`), for example:
   * `public/placeholders/my-portrait.webp`
   * `public/placeholders/project-1.webp`
2. You can reference them anywhere in code as:
   * `/placeholders/my-portrait.webp`
   * `/placeholders/project-1.webp`
3. When you are ready to upload images to Payload CMS instead, you can simply upload them at `http://localhost:3000/admin` in the **Media** collection!
